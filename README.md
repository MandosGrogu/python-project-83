#### Критерии, предъявляемые к ссылкам

1. Длина ссылки не должна превышать 255 символов.
2. URL адрес должен быть формата "https://dmn2.dmn1".


## Установка

Запустите команду 
```
python3 -m pip install --user git+https://github.com/MandosGrogu/python-project-83.git
```
